# Mueblería — Frontend

Aplicación web de la Evaluación Final Integradora de Programación III. El frontend se desarrollará con Next.js y consumirá la API REST del proyecto de Ingeniería de Software, desarrollado con Django REST Framework.

## Integrantes

- Carla Nadalig
- Mateo Urquiza
- Sebastián Maldonado

## Tecnologías previstas

- Next.js con App Router
- React y Tailwind CSS
- React Hook Form y Zod
- Context API
- Vitest
- API REST con Django REST Framework

## Requisitos

- Node.js y npm
- Acceso a la API del backend

## Instalación y ejecución

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000) en el navegador.

## Variables de entorno

Crear un archivo `.env.local` en la raíz:

```env
NEXT_PUBLIC_API_URL=http://localhost:8000/api
```

Reemplazar la URL cuando el backend esté publicado.

## Tests

```bash
npm run test
```
